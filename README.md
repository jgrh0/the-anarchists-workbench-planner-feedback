# The Anarchist's Workbench Planner Feedback

Use this repository to leave feedback, report issues, and share ideas for improving the planner.

## About The App

The Anarchist's Workbench Planner is a browser-based planning tool for an
Anarchist's Workbench-style build. I built it to help with my own workbench
build, and it is an unofficial project. I made it public and free of charge so
it can help other woodworkers starting the same build.

If you need the book itself, buy it from the publisher:
[Lost Art Press - The Anarchist's Workbench](https://lostartpress.com/products/the-anarchists-workbench).

## Core Functionality

- Validates key bench and stock inputs before generating plans
- Produces grouped cut lists for structural and optional part groups
- Estimates material needs using two planning strategies:
  - `rip-first`
  - `crosscut-first`
- Supports optional groups like shelves, planing stop, and leg vice jaw
- Lets users share and restore configurations through URL/local save behavior

## How To Leave Feedback

1. Open the repository Discussions or Issues tab.
2. Add a clear title and short description.
3. Include screenshots, steps, and expected behavior when relevant.
